# Scholarship Practice - Year 5 (AAS-style)

Parent-friendly practice for Alexia Su (Year 4 now, Year 5 stretch).

**Practice only - not an official AAS paper.**

## What is included

| Section | Time | Items |
|--------|------|-------|
| Abstract Reasoning | 40 min | 28 MCQ |
| Mathematics | 40 min | 28 MCQ |
| Reading Comprehension | 40 min | 22 MCQ |
| Written Expression | 25 min | 1 task + rubric |

Full mock ~2h25m. Prefer one section first.

## How Joe runs it

Needs Node.js (LTS).

```
cd scholarship-practice
npm install
npm run dev
```

Open the URL Vite prints (usually http://localhost:5173).

```
npm run build
npm run preview
```

Built files land in dist/.

## How to use with Alexia
1. One section first.
2. Quiet space; instruction questions OK.
3. Review explanations after MCQ.
4. Parent marks Written Expression with rubric.
5. Do not stress Year 4 scores on Year 5 stretch.
6. Progress saves in browser localStorage.
